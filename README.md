## README

你可以通过查看各 commit 的历史版本，来获取每个阶段的代码。

这份代码虽然是我的心血之作，不过还是要提醒各位，它并不具有全盘参考的价值，一定要批判性地阅读。

一是因为我实验课最后的得分其实并不高。虽然我课下没什么问题，期中期末考试加文法增量开发的部分也都过了，但是竞速排序实在是拉了，可能要排在三位数了。主要是当时时间确实比较紧，代码优化拖到了最后一周才做，有很多大的都没来得及做。而且当时并没有参透 AI 大法，代码全是纯手写的（我觉得这 8k 行可能是我人生巅峰了，以后再不可能手写出这么多代码了），生产力这块确实没跟上。人家加个大功能可能也就跑个十分钟，我一写得写一天，一学期时间全花这玩意上了。

二是我的代码架构和思路也比较逆天。我写代码的时候极少参考其他人的架构，所以经常会科技树点歪，闭门造车出一些非常奇葩但能 work 的东西。我花了很多时间在研究如何花式利用 MIPS 指令集特性和 MARS 支持的语法上，这东西大概属于邪修了，对 MIPS 感兴趣的可以研究一下。其实我觉得先翻译成 LLVM 再翻译成 MIPS 本身就是一个对竞速非常不友好的行为，强烈建议大家尝试一下不用中间代码（或者自创一个没有那么多煞笔语法规则的魔改版中间代码），直接翻译成 MIPS ，这样优化的空间应该会更大。

随代码附上当年的文法规则、期末提交的设计文档，以及当年期中期末考题的回忆版，位于最后一个 commit 的 document 目录中，供大家参考。

说实话那个文档写的也都挺烂的，所有的文档都是我在 ddl 前的最后一天通宵补的，所以写得不是很详细，而且太困了神志不清醒的时候会胡言乱语。我记得元旦放假的时候我回家待了两天（其实也完全没歇着，每天都在赶这破壁代码优化），最后一天我还正好要坐四个来小时高铁回北京，讲真实在累爆缸了。我听说人一辈子只有五次爆缸的机会，我觉得那个学期我就至少用了两次。哎跑题了不说了，大家注意身体。

PS：在“最后修复了一些极其离谱的 bug ”这个 commit 中，有一些非常重要的勘误，一定一定一定要记得看！
