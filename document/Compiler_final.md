## 2025 编译实验期末考试

期末考试包括竞速排序、增量开发题和简答题三个部分。

考试的竞速排序和课下的竞速排序流程基本相同（当然测试点肯定是不同的），主要是为了防止有人针对课下竞速排序测试点特调。这部分不需要做任何修改，只需要将优化后的版本上传到对应提交窗口即可。

增量开发题包括课下强测以及两个新文法，保证输出结果正确即可，没有竞速要求。题目不太难，只需要按照词法分析、语法分析、错误处理、中间代码生成四步认真操作，问题都不会太大。一般可能会翻车的地方反倒是课下强测，强测极其之变态，几乎所有人优化后的版本都无法通过强测，所以一定要做好两手准备，必要时切换到未优化的版本进行增量开发！

简答题分为 Pcode/LLVM 和 MIPS 两个版本，只需要回答自己使用的目标代码对应的版本（不过我只记了 MIPS 的题）。简答题基本纯送分，不过一定要预留充足的时间来做，千万不要在增量开发那里恋战而把这部分送的分丢掉！

### 增量开发题

(1) 增加 Token `>>` `->` `cin` ，TokenType 分别为 `SHR` `LEFTTORIGHTTK` `CINTK` ；
(2) 增加文法 `Stmt → 'cin' '>>' lVal ';'` ，可能出现缺分号错误和向常量赋值错误；
(3) 修改文法 `MulExp → UnaryExp | MulExp ('*' | '/' | '%') UnaryExp` 为 `MulExp → UnaryExp | MulExp ('*' | '/' | '%' | '->') UnaryExp` 。

语义：
(1) `cin` 只用于对可赋值左值 `lVal` 进行输入，语义等价于 `getint()` 函数，一次性只会读入一个变量值；
(2) 运算符 `->` 的含义为 `a -> b == a + (a + 1) + (a + 2) + ... + b` ，测试数据保证所有 `a -> b` 运算中 `a <= b` ，无需考虑 `a > b` 的情况。

### 简答题（MIPS）

结合下面一段代码，根据你编译器的实际情况，回答问题：

```c
int partition(int a[], int l, int r) {
    int pirot = a[r];
    int i = l - 1;
    int j;
    int useless1 = 10 * 10 / 10 - 10;
    int useless2 = useless1 * useless1;
    for (int j = l; j < r; j = j + 1) {
        int cmp = a[j] - pirot + useless2;
        if (cmp <= 0) {
            i = i + 1;
            swap(a, i, j);
        }
    }
    swap(a, i + 1, r);
    return i + 1;
}

void qsort_opt(int a[], int l, int r) {
    if (l < r) {
        int p = partition(a, l, r);
        int left = l + 0 * 0 + 10086 - 10086;
        int right = r - 0 * (1 + 2 * 3 / 3 + 4 % 2);
        qsort_opt(a, left, p - 1);
        qsort_opt(a, p + 1, right);
    }
}
```

（只记了和题目有关的函数，其它函数略）

(1) 在你的编译器中，如果某个函数具有超过 4 个参数，在调用该函数时该如何传递参数？在执行该函数时该如何获取参数？
(2) 在你的编译器中，在调用函数时，是否会对临时寄存器（即 `$t0 - $t9` ）中的值进行保护？如果不进行保护的话，如何保证调用函数前后局部变量的值不变？
(3) 在你的编译器中，在访问数组元素 `a[j]` 时，如何使用 MIPS 指令序列计算出 `a[j]` 在实际内存中的物理地址？
(4) 对于函数 `partition()` 和 `qsort_opt()` ，你的编译器做了哪些优化？如果没做优化的话，描述一些可能的优化策略。
